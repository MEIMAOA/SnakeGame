# SnakeGame v9.0.0

贪吃蛇 + 明日方舟式塔防（3D）游戏，Windows 11 风格 UI。

## 下载
见 [Releases](Releases/) 目录：
- `SnakeGame-v9.0.0-Windows64.zip`（Windows 64 位）
- `SnakeGame-v9.0.0-Windows32.zip`（Windows 32 位）
- `SnakeGame-v9.0.0-WindowsARM64.zip`（Windows on ARM）

解压后运行 `SnakeGame.exe`。

## 玩法
- 贪吃蛇：经典 / 计时赛 / 占领 4v4 / 极速 / 撤离·搜打撤（2D 俯视）
- 塔防（3D）：10 关逐一解锁，技能、阻挡、敌人动线预览、WIN11 风格界面

## 构建
用 Tuanjie/Unity 2022.3 打开工程，执行菜单 `ArknightsTD/打包 Windows x64 / x86 / ARM64`。
